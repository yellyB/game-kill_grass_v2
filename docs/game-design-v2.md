# 풀 좀 베겠습니다 v2 — 게임 디자인 요약

> 확정 결정 종합 (2026-09-15). 세부·근거는 `pc-port-plan.md`, 파워업/아이템 목록은 `powerups.md` 참조.
> 상태: **기획 확정 단계.** 클린 슬레이트(원본 코드/에셋 삭제) 완료, 코드는 시뮬(S0) 이후 착수.

---

## 1. 컨셉
- 벌초꾼이 끝없이 자라는 **과성장(자연)을 정리**하는 방치형 + **로그라이트**. PC(스팀) 우선, 멀티플랫폼 고려.
- 원본 모바일 게임 리메이크: **몬스터 제거**(세계관상 뜬금없음) → 식물 테마로 통일.

## 2. 핵심 루프 (세션)
> 월드 선택 → **이동(자동 베기)로 풀 수확 → 코인** → **세션 레벨업(파워업 3택)** → **아이템 줍기/발동** → **씨앗 모아 거목 소환** → **거목 격파 = 승리 종료** → 메타 성장 → 반복

- 세션 45초. **종료 = ①거목 격파(승리·월드 클리어) 또는 ②시간초과(실패, 코인만).**
- **실패는 시간초과만**(죽음 없음). 거목 공격 패턴에 맞으면 **잠시 멈춤(스턴)** → 시간 손실이 페널티(시간=자원).

## 3. 입력 (PC)
| 입력 | 역할 |
|---|---|
| WASD/화살표 | 이동 (유일한 이동 수단, 이동=자동 베기) |
| 마우스 좌클릭 | UI 조작 전용 |
| 스페이스 | 메뉴=시작 버튼 / 인게임=**즉발 아이템 발동** |
| ESC | 인게임 나가기 다이얼로그 |
| 아무 키/클릭 | 세션 종료 화면 → 메인 메뉴 |

## 4. 필드 요소
- **강한 풀(덤불류)**: 기존 5종+황금풀에 고체력 등급 추가(MultiMesh).
- **정예 식물**: 산재 스폰, 고체력, 큰 코인 + 확률 보상.
- **거목**: 월드 목표. **씨앗 N개 모으면 소환**(씨앗=필드 랜덤 스폰). 월드별 고유 색상, 공격 패턴(종류별 랜덤), 처치 시 **증표 아이콘**(열쇠 대체).
- **씨앗**: 필드 랜덤 스폰, 밟아 획득 → N개면 거목 등장.

## 5. 성장 시스템

### 인런 (세션 내, 종료 시 리셋)
- **세션 레벨업 → 파워업 3택**(지속 버프 = 빌드). 개방형 곡선(초반 1~2레벨 → 성장 후 ~10/45초, 그 이상은 매우 어려움).
- **즉발 아이템**: 맵 발견 + 상점 구매 → **슬롯 저장 → 스페이스 발동**(일회성). 슬롯 1→2→3(코인 스킬). = LoL 소환사 스펠.

### 메타 (영구)
- **코인**: 스킬·무기 구매/강화.
- **보석**: 상위 스킬 티어 심화. 월드 **최초 클리어 1회** 보상(초월 레벨별도 최초 1회).
- **게임 레벨(UI 표기 "레벨", 최대 15)**: **거목 처치로 상승** → 스킬/룬 자동 해금(노드 개방). 거목 격파 = 3중 보상(월드 클리어+레벨+코인).
- **룬(키스톤)**: **하나 장착, 세션 내내 지속 패시브.** 레벨로 3~5개 점진 해금. = LoL 룬. (후보: 맹공/축재/벌목꾼/파종/만개)
- **초월**: 클리어 월드 재강화(코인/보상↑, 보석). **비용 게이트**(초월 비용 ≈ 월드 4~5 해금 비용 → 월드 4~5 경제에서나 가능).

### 파워업/아이템 (총 50종 — `powerups.md`)
- 파워업(지속) 33 + 아이템(즉발) 17. (무기형 5종 제거 — 정적 풀에 안 맞음)

## 6. 스킬트리 (원본 16개 재편 — `pc-port-plan.md §3.8`)
- 대부분 유지. **재정의**: `monster_damage`→거목 피해, `chest_chance`→씨앗 확률, `fury_rate`→레벨업 게이지 충전. **신규**: 아이템 슬롯.
- 해금 축: **코인**=구매/강화, **보석**=상위 티어, **게임 레벨**=노드 개방.

## 7. 진행 / 월드
- 7월드, **거목 격파 = 월드 클리어 → 다음 월드 해금**(+코인 비용). **열쇠 제거**.
- **월드별 약한 특성**(환경+경제 파밍 차별화, 저우선).
- **엔딩 월드**: 최후에 하나 추가(쉬움, 미정, 보류).

## 8. UI
- **텍스트 지양, 아이콘/색상 우선. 원본에 없던 신규 텍스트 금지.**
- 메뉴: 좌상단 설정 아이콘 제거 → 버튼 목록(강화-종료 사이) "설정" 버튼. 돈·보석·**레벨 숫자+아이콘**(클릭→레벨 보상 트랙 창, 배틀패스식).
- 설정: 메뉴/인게임 공용 팝업(언어 드롭다운 포함).
- 인게임 나가기: 우하단 버튼 제거, ESC→세로 버튼(처음으로/계속) + 설정 버튼.

## 9. 로컬라이제이션
- **스팀 지원 전 언어(약 29종)**, **전부 기계번역**. 한국어 원문=키. Noto 폰트 폴백. (`pc-port-plan.md §3.6`)

## 10. 아키텍처 (필수)
- **Sim-first**: 게임 실행 없이 수치로 밸런싱. `core/`(순수 로직·데이터, SSOT) + `sim/`(헤드리스). 게임/시뮬이 같은 코드 공유.
- **워크플로우**: 게임 개발 **전에** 시뮬 구조 구축 → 밸런싱 → 수치 확정(freeze) → 그다음 게임 개발.
- 시뮬 필수 포함: 스킬·파워업·아이템(+슬롯)·게임 레벨·룬 / 풀 체력·공격력·드롭 코인. (`pc-port-plan.md §9`)
- **멀티플랫폼**: `PlatformService` 추상화(진동·뒤로가기·플랫폼 분기 일원화).

## 11. 미결정 / 보류 (나중)
- 게임 레벨 **해금 테이블**(레벨별 개방 내용) · **룬 최종 목록/수치** · **엔딩 월드** · **거목 공격 패턴 구체** · **월드 특성 수치** · **추가 스킬 후보**(스턴 감소·거목 XP↑ 등)
- 전부 **수치/밸런싱은 S0 시뮬 단계**에서.
