# **MVP 스펙 – 실제 개발 단위 분해**

## **MVP 목표 (다시 못 박기)**

- 풀 하나 베는 게 재밌다
- 10분 플레이 가능
- 저장되고 다시 켜면 이어진다

## **PHASE 0. 프로젝트 뼈대 (반나절)**

### **0-1. Godot 프로젝트 생성**

- Godot **4.3**
- 2D 템플릿
- 해상도: 세로 기준 (예: 1080x1920)

### **0-2. 기본 폴더 구조**

```jsx
/scenes
  /core
  /world
  /ui
/scripts
/resources
/autoload
```

### **0-3. Autoload 등록**

- GameManager.gd
- SessionManager.gd
- SaveManager.gd

> 이 세 개는 심장이다. 나중에 건들지 마라.
>

## **PHASE 2. 풀 기본 시스템 (1.5일)**

### **2-1. Grass Scene**

- Area2D (Grass)
    - GrassVisual (Polygon2D)
    - CollisionShape2D
    - GPUParticles2D
    - RegenTimer
- 체력 변수
- 베기 함수

### **2-2. 자동 베기**

- Player에 Area2D 공격 범위
- 풀과 오버랩 시 자동 대미지

### **2-3. 풀 제거 & 재생**

- 베임 → 숨김 (cut state)
- Timer → 재생 (grow animation)

### **2-4. 무한 맵 (청크 시스템)**

- 청크 기반 풀 생성 (chunk_size: 400)
- 플레이어 주변 청크만 로드 (render_distance: 3)
- 멀어지면 청크 언로드
- 청크 좌표 seed로 일관된 생성

**완료 기준**

- 걸어가면 풀이 잘린다
- 시간이 지나면 다시 난다
- 무한히 걸어가도 새 풀이 생성된다

**완료 기준**

## **PHASE 8. 몬스터 피격 패널티 시스템**

### **8-1. 피격 판정**

- 플레이어-몬스터 거리 45px 이내 시 피격 발동
- 매 프레임 `_check_monster_collision()` 호출
- 무적 상태이면 무시

### **8-2. 스턴 효과**

- 2초간 이동 불가 (`input_direction = Vector2.ZERO` 강제)
- 스턴 중 공격 속도 2배 느림 (`attack_timer.wait_time *= 2.0`)
- HUD에 "STUNNED!" 빨간 알림 표시

### **8-3. 코인 드롭 패널티**

- 세션 코인의 5% 차감 (`GameManager.add_money(-penalty)`)
- `session_money`가 음수가 되지 않도록 `max(0, ...)` 보장
- 차감된 금액을 플레이어 주변에 코인으로 스폰 (최대 10개)
- 빨간색 플로팅 텍스트로 차감 금액 표시 (`setup_penalty()`)

### **8-4. 무적 시간**

- 3초 무적 (스턴 2초 + 유예 1초)
- 무적 중 플레이어 깜빡임 (0.2초 주기 alpha 토글)
- 무적 종료 시 alpha 복구

### **8-5. 피격 이펙트**

- `player_visual` 빨간 플래시 → 0.15초 복구

**수정 파일**

| 파일 | 변경 내용 |
|------|-----------|
| `scripts/player.gd` | `player_hit` 시그널, 스턴/무적 상태, 충돌 체크, 코인 드롭 패널티, 공격 속도 패널티 |
| `scripts/hud.gd` | `player_hit` 시그널 연결, "STUNNED!" 알림 표시 |
| `scripts/floating_text.gd` | `setup_penalty()` 메서드 추가 (빨간 음수 텍스트) |
| `autoload/game_manager.gd` | `add_money()` 음수 처리 보장 (`session_money >= 0`) |

**완료 기준**

- 몬스터에 접근하면 피격 이펙트 + 스턴 발생
- 스턴 중 이동 불가, 공격 속도 절반
- 세션 코인 5% 드롭, 빨간 텍스트 표시
- 3초 무적 중 재피격 없음, 깜빡임
- 세션 머니 0일 때 피격해도 에러 없음
