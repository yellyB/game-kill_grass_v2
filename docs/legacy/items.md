# 아이템

## 파워업 아이템 (세션 내 버프)

- 몬스터 처치 시 30% 확률로 파워업 드롭
- 지속 유형: '즉발성', 'n초간 지속', '세션 내 지속' 세 가지
- 지속형은 게임 창 내에 남은 초가 표시됨
- 등장 확률에 가중치가 있으며, 일반 버프는 자주, 강력한 버프는 드물게 등장

### 일반 (weight 10)
- 어택 부스트: 공격 속도 +25%
- 와이드 어택: 공격 범위 +25%
- 메가 마그넷: 수집 범위 +50%
- 라이트닝 대시: 이동 속도 +50%
- 크리티컬 서지: 치명타 확률 100% + 치명타 피해 2배. 세션 내 지속

### 보통 (weight 5)
- 골든 럭: 황금풀 절단 시 랜덤 파워업 자동 획득. 세션 내 지속
- 크리티컬 리퍼: 치명타 시 주변 풀 3개 즉사. 세션 내 지속
- 엑스트라 타임: 세션 지속 시간 +5초. 즉발성
- 골드 러시: 코인 2배 수집 (10초 지속)
- 골든 블룸: 주변 일정 범위 풀을 모두 황금풀로 변환. 즉발성
- 더블 오어 더스트: 50% 확률로 모은 코인 2배 or 모두 증발. 즉발성
- 몬스터 퓨리: 분노 게이지 20% 즉시 충전. 즉발성
- 오버드라이브: 공속 2배, 이속 -50% (10초 지속)
- 블랙홀: 모든 드롭된 코인 흡수. 즉발성

### 희귀 (weight 2)
- 하베스트 매드니스: 수집범위, 공속, 이속 모두 대폭 증가 (5초 지속)
- 필드 클리어: 맵 전체 풀 클리어. 즉발성

## 재료 아이템 (16종)

몬스터 드롭으로 획득. 사망 시 드롭 테이블의 가중치에 따라 1개 드롭.

| 재료 | 드롭 몬스터 | 사용처 |
|------|-------------|--------|
| 번개 먹은 배터리 껍질 | 슬라임 | 엔진 코어 |
| 질긴 슬라임 조각 | 슬라임 | 바퀴 |
| 차축 뼈대 | 멧돼지 | 바퀴 |
| 굴러다니는 바퀴 잔해 | 멧돼지 | 바퀴 |
| 과성장 생체 응축체 | 멧돼지 | 운전기사 |
| 왜곡된 볼트 조각 | 잔디 기사 | 바퀴 |
| 압축된 이세계 철편 | 잔디 기사, 골렘 | 범퍼, 유리 모듈 |
| 생체 연료 포자 | 마도사 | 범퍼 |
| 뒤틀린 시간 포자 | 마도사 | 내비게이션 |
| 바람 머금은 잔디 섬유 | 마도사 | 운전기사 |
| 몬스터 핵 | 골렘 | 범퍼, 내비게이션 |
| 침식된 백골 프레임 | 골렘 | 운전기사 |
| 투명 수정 파편 | 수정 사슴 | 유리 모듈 |
| 강화 유리 결정핵 | 수정 사슴 | 유리 모듈 |
| 과열된 엔진 심장 | 드래곤 | 엔진 코어 |
| 드래곤 배기가스 결정 | 드래곤 | 엔진 코어 |

## 부품 제작 (6종)

재료를 조합하여 중간 아이템(부품) 제작. 각 부품은 소지 수량에 비례하여 버프를 제공.

### 개념상 바퀴 (최종 필요 4개)

| 재료 | 수량 |
|------|------|
| 굴러다니는 바퀴 잔해 | 2 |
| 차축 뼈대 | 1 |
| 왜곡된 볼트 조각 | 8 |
| 질긴 슬라임 조각 | 4 |

**버프: 이동속도 증가** — 개당 +8%, 최대 +32%

### 폭발하는 엔진 코어 (최종 필요 10개)

| 재료 | 수량 |
|------|------|

| 번개 먹은 배터리 껍질 | 4 |

**버프: 공격범위 증가** — 개당 +10%, 최대 +100%

### 충격 무시 범퍼 (최종 필요 2개)

| 재료 | 수량 |
|------|------|
| 압축된 이세계 철편 | 5 |
| 생체 연료 포자 | 1 |
| 몬스터 핵 | 1 |

**버프: 피격 패널티 감소** — 개당 -25%, 최대 -50%

|------|------|
| 뒤틀린 시간 포자 | 4 |

**버프: 몬스터 탐지** — 화면 밖 몬스터 위치를 빨간 화살표로 표시

## 최종 조립: 이세계 트럭

부품 6종 + 졸음 약을 모두 모아 조립.

| 부품 | 필요 수량 |
|------|-----------|
| 개념상 바퀴 | 4 |
| 폭발하는 엔진 코어 | 10 |
| 충격 무시 범퍼 | 2 |
| 이세계 내비게이션 | 1 |
| 강화 유리 모듈 | 6 |
| 운전기사 | 1 |
| 졸음 약 | 1 |

- 졸음 약: 마지막 월드(용의 봉우리) 상자에서 드롭
- 부품 6종 완성 시 최종 조립 해금, 졸음 약 없으면 힌트 표시
