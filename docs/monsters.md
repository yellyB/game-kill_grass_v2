# 몬스터 & 보스 정보

## 개요

몬스터는 분노 게이지를 채워 소환하는 보스 형태로 등장합니다.
각 월드에 1종의 보스가 매핑되어 있으며, 플레이어가 풀을 벨 때 분노 게이지가 차오릅니다.
게이지가 가득 차면 해당 월드의 보스가 소환됩니다.

## 보스 행동

- **이동**: 소환 즉시 플레이어를 향해 추격
- **스프라이트**: 5프레임 애니메이션 (숨쉬기/흔들림 루프, 0.18초/프레임)
- **좌우 반전**: 이동 방향에 따라 flip_h 적용
- **피격 반응**: 빨간 플래시 (0.15초) + 슬래시 효과음
- **사망 연출**: 확대 → 흔들림 + 페이드아웃 + 사망 효과음
- **드롭**: 파워업 (30% 확률), 초월 보스는 보석 드롭

## 피격 패널티

보스와 접촉 시:
- 이동 속도 감소 + 공격 속도 감소 디버프 (1.5초)
- 3초간 무적 (연속 피격 방지)

## 난이도 흐름

초반: 슬라임 → 멧돼지
중반: 기사 → 마도사
후반: 수정 사슴 → 잔디 골렘
최후반: 드래곤 배기가스
