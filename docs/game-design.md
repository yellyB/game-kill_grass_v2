# 풀죽이기 (Excuse Me, Mowing through) - 게임 기획서

## 디자인 철학

> 이 게임의 중심은 아이템도, 숫자도 아니다.
> 풀을 베는 '순간' 자체가 재미여야 한다.

- 베기: 유일한 본질
- 아이템: 베기 뒤에 따라오는 보상
- 업그레이드: 베는 방식을 바꾸는 변주
- 저장: 욕심을 관리하는 장치

> 핵심 컨셉: 캐릭터는 움직이지 않는다. 대신 세계가 잘린다.

### 성공/실패 기준
- 성공: "베는 게 재밌다"
- 실패: "업그레이드가 재밌다"

---

## 개요
풀을 베어서 돈을 모으는 방치형 모바일 게임.
플레이어가 이동하면 자동으로 범위 내 풀을 베고, 떨어진 코인을 수집하여 골드를 획득한다.
7개 월드를 해금하며 진행. 각 월드의 분노 게이지를 채워 보스를 소환하고 처치한다.

- **엔진**: Godot 4.3
- **장르**: 방치형 / 아이들 게임
- **플랫폼**: 모바일 (Android), PC

---

## 게임 플로우

```
메인 메뉴 → [PLAY] → 게임 세션 (타이머) → 세션 종료 → 메인 메뉴
             ├ [무기]  → 무기 상점 패널
             ├ [강화]  → 업그레이드 패널 (스킬 트리)
             └ [QUIT]  → 게임 종료
```

### 메인 메뉴
- PLAY: 게임 세션 시작 (월드 선택 후)
- 무기: 무기 구매/업그레이드 패널
- 강화: 스킬 트리 업그레이드 패널
- QUIT: 게임 종료
- 타이틀 "KILL GRASS" 숨쉬기 애니메이션
- 월드 선택 / 초월(강화) 시스템

### 게임 세션
- 제한 시간 내에 최대한 풀을 베어 돈을 벌기
- 세션 시간: 45초 (세션 시간 스킬로 최대 90초까지 증가)
- 화면 상단 중앙에 남은 시간 표시
- 10초 이하일 때 타이머 빨간색으로 변경
- 세션 종료 시 수집 내역 + 보스 보상 표시
- 터치하여 메인 메뉴로 복귀
- 게임 중 "처음으로" 버튼으로 메뉴 복귀 가능 (확인 다이얼로그)

## 핵심 시스템

### 이동 방식
- 플레이어는 화면 중앙에 고정
- 월드(WorldRoot)가 플레이어 입력의 반대 방향으로 이동
- 배경은 카메라를 따라다니며 무한하게 보임
- 입력: 키보드 (WASD/방향키), 터치 드래그 (모바일)

### 무한 맵 (청크 시스템)
- 청크 기반 무한 풀 생성 (`grass_spawner.gd`)
- 청크 크기: 400x400
- 렌더 거리: 3 청크
- 플레이어 주변 청크만 로드, 멀어지면 언로드
- 풀 밀도 업그레이드에 따라 청크당 풀 수 변동

### 풀 렌더링 (MultiMesh)
- MultiMeshInstance2D로 모든 풀을 1 draw call로 렌더링
- GPU 셰이더로 바람 흔들림 애니메이션 (CPU 부하 0)
- 풀 데이터는 Dictionary로 관리 (노드 없음)

### 풀 종류 (5종 + 황금풀)
| idx | 종류 | 체력 | 드롭 | 재생시간 | 색상 | 등장 조건 |
|-----|------|------|------|----------|------|-----------|
| 0 | 새싹 | 4 | $1 | 22초 | 밝은 초록 | 풀 등급 레벨 의존 |
| 1 | 잔디 | 18 | $5 | 23초 | 청록색 | 풀 등급 레벨 의존 |
| 2 | 여린풀 | 38 | $30 | 24초 | 어두운 청록 | 풀 등급 레벨 의존 |
| 3 | 강한풀 | 75 | $80 | 25초 | 딥 블루 | 풀 등급 레벨 의존 |
| 4 | 초강풀 | 130 | $200 | 26초 | 다크 블루 | 풀 등급 레벨 의존 |
| 5 | 황금풀 | 80 | $100 | 25초 | 황금색 | 황금풀 확률 스킬 (기본 0%) |

### 풀 등장 확률
- 황금풀: 미투자 시 0%, 황금풀 확률 스킬 투자 시 최대 1.0%
- 나머지는 풀 등급 스킬 레벨에 따라 변동:
  - 홀수 레벨: 현재 등급 → 다음 등급 50%까지
  - 짝수 레벨: 다음 등급 100%까지
  - Lv.8: 초강풀 100%

### 코인 시스템
- 풀을 베면 해당 위치에 코인 생성 (WorldRoot 자식)
- 코인 색상: 브론즈($0~99), 실버($100~499), 골드($500~999), 다이아($1,000+)
- 고액 코인(브론즈 $50+, 실버 $300+, 골드 $750+)은 피라미드형 3개 쌓인 비주얼
- 코인 스폰 시 팝 애니메이션
- 코인은 월드 좌표에 고정됨
- 자석 범위 내 접근 시 자동으로 끌려옴 (기본 범위 50, 스킬로 최대 260)
- 30 거리 내에서 자동 수집
- 수집 시 플로팅 텍스트 ("+금액") 표시 (배치 합산)

### 자동 공격
- 플레이어가 이동 중일 때 자동으로 범위 내 풀 공격
- 공격 주기: 기본 0.7초, 공격 속도 스킬로 최소 0.1초까지
- 공격 범위: 기본 60, 공격 범위 스킬로 최대 340
- 공격 개수: 기본 1개, 공격 개수 스킬로 최대 46개
- 피격 시 풀이 0.1초 동안 흰색 플래시
- 풀 체력이 0 이하가 되면 베어짐 → 코인 드롭

| 1 | 나뭇가지 | 무료 | 1 |
| 2 | 녹슨 식칼 | $90 | 2 |
| 3 | 피자 커터 | $450 | 3 |
| 4 | 전기 파리채 | $1,200 | 4 |
| 5 | 뜨거운 다리미 | $2,600 | 5 |
| 6 | 매우 화난 고양이 | $6,000 | 7 |
| 7 | 체인소 | $13,000 | 9 |
| 8 | 마법 지팡이 | $29,000 | 10 |

별도 상세: `weapons.md`

### 업그레이드 시스템 (스킬 트리)
3개 그룹, 16개 스킬의 트리 구조:
- **무기**: 공격력, 공격 속도, 공격 범위, 치명타 확률/피해, 몬스터 피해
- **수확**: 풀 밀도, 풀 등급, 공격 개수, 황금풀 확률/보상, 수집 범위
- **탐험**: 이동 속도, 세션 시간, 상자 확률, 분노 속도

스킬별 개별 비용 테이블 적용 (틱 단위). 특정 레벨은 보석으로 해금 필요.
별도 상세: `skill-tree.md`

## 몬스터 시스템 (분노 보스)

### 분노 게이지
- 풀을 벨 때마다 분노 게이지 증가
- 게이지가 가득 차면 해당 월드의 보스 몬스터 소환
- 분노 속도 스킬로 게이지 증가 배율 상승

### 보스 몬스터 (7종, 월드별 1종)
| 월드 | 몬스터 | 체력 | 속도 |
|------|--------|------|------|
| 1 | 번개 먹은 슬라임 | 60 | 50 |
| 2 | 과성장 멧돼지 | 230 | 60 |
| 3 | 잔디 기사 | 1,400 | 48 |
| 4 | 스포어 마도사 | 5,800 | 54 |
| 5 | 수정 사슴 | 31,500 | 72 |
| 6 | 잔디 골렘 | 58,000 | 40 |
| 7 | 드래곤 배기가스 | 145,000 | 80 |

### 보스 행동
- 플레이어 추격 AI (소환 즉시 플레이어를 향해 이동)
- 5프레임 스프라이트 애니메이션 (숨쉬기/흔들림 루프)
- 이동 방향에 따라 좌우 반전
- 피격: 빨간 플래시 + 슬래시 효과음
- 사망: 확대 → 흔들림 + 페이드아웃 → 파워업 드롭 (30% 확률)
- 초월 보스 처치 시 보석 드롭

### 피격 패널티
- 보스와 접촉 시 이동 속도 감소 + 공격 속도 감소 디버프 (1.5초)
- 3초간 무적

별도 상세: `monsters.md`

## 월드 시스템

7개 월드, 각각 고유한 배경색/풀 색상/보스/BGM:
| 월드 | 이름 | 해금 비용 | 보스 몬스터 |
|------|------|-----------|-------------|
| 1 | 슬라임 늪 | 무료 | 슬라임 |
| 2 | 들판 | $100 | 멧돼지 |
| 3 | 기사의 성벽 | $1,000 | 잔디 기사 |
| 4 | 마법의 숲 | $10,000 | 마도사 |
| 5 | 수정 호수 | $25,000 | 수정 사슴 |
| 6 | 고대 유적 | $50,000 | 잔디 골렘 |
| 7 | 용의 봉우리 | $100,000 | 드래곤 |

- 해금 조건: 코인 + 이전 월드 상자에서 획득한 열쇠
- 월드별 풀/배경 고유 색상
- 월드별 풀 체력/보상 배율 적용

### 초월 시스템
- 월드별 보스를 반복 처치하여 초월 레벨 상승
- 초월 레벨 증가 시 풀 체력 × (1 + 레벨 × 0.4), 보상 × (1 + 레벨 × 0.5)
- 초월 보스 처치 시 보석 드롭 (초월 레벨 수만큼)
- 보석으로 특정 스킬 레벨 해금

### 열쇠 & 상자 시스템
- 상자는 청크 진입 시 확률적으로 스폰 (상자 확률 스킬, 기본 0%)
- 상자는 "monsters" 그룹 → 플레이어 자동공격으로 파괴
- 상자 파괴 → 열쇠/아이템 드롭 → 플레이어에게 비행 → 수집

## HUD 정보

### 화면 표시 요소
- **상단 좌측**: 무기 정보 (이름, 레벨)
- **상단 중앙**: 타이머 (남은 세션 시간) + 진행바
- **상단 우측**: 보유 골드 ($X,XXX 형식), 보석 수
- **하단 중앙**: "처음으로" 버튼
- **열쇠 획득 알림**: 우측 상단, 시안색, 1.5초 표시 후 페이드아웃

### 디버그 UI (개발 빌드 전용)
- 데이터 초기화 버튼
- +$100,000 버튼
- +보석10 버튼
- 월드 전체해금 버튼

## 저장/불러오기

### 저장 데이터
- 보유 골드, 보석
- 스킬 레벨/서브레벨 (16개 스킬)
- 무기 레벨
- 해금된 월드, 보유 열쇠
- 월드별 초월 레벨
- 보석 해금 스킬, 수집된 보석 레벨

### 저장 시점
- 세션 종료 시 자동 저장
- 앱 종료 시 자동 저장

### 저장 경로
- `user://savegame.json` (JSON 형식)
- macOS: `~/Library/Application Support/Godot/app_userdata/풀죽이기/savegame.json`
