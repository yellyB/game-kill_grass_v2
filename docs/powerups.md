## 1. 설계 원칙

### 두 계층 분리 (확정)
- **파워업(지속형 버프)** = "말 그대로 능력을 올려주는" 지속 효과. 세션 동안 유지 = 빌드.
  - 획득: **레벨업 3택**(게이지 만충, `pc-port-plan.md §3.3`). 신중히 고름.
- **아이템(즉발/일회성 소모품)** = 주우면 발동하는 일회성 효과. **파워업 아님**.
  - 획득: **맵에서 줍기**(구 상자 대체). **슬롯에 저장 → 스페이스로 발동**(§4.10).

### 성장 축
- **인런 성장(세션 내, 종료 시 리셋)** = 파워업 + 아이템.
- **메타(영구) 성장** = 스킬트리 + 무기. 파워업과 역할 분리(인런=배율/특수, 메타=기본치).

### 공통 규칙
- **3택 구성**: 레어도 가중치 추첨, 중복/최대스택 도달 제외(원본 `powerup_selection.gd:168-197` 계승).
- **빌드 다양성**: 누적형(커먼) + 빌드정의형(레어) + 조건/시너지형을 고루.
- **상자 제거**: 나무 상자 → 맵 아이템 픽업으로 대체(테마 일관).

## 2. 데이터 구조 (필드)

원본 `POWERUP_DATA` 배열 방식 유지 + 필드 확장:

| 필드 | 설명 |
|------|------|
| `type` | 코드 식별자(snake_case) |
| `name` / `desc` | 표시 이름/설명 (전부 `tr()` 대상) |
| `rarity` | `common` / `uncommon` / `rare` / `epic` |
| `category` | 공격 / 수확 / 기동 / 치명 / 황금 / 시간 / 도박 / 액티브 / 성장 / 시너지 |
| `stackable` | 중복 획득 누적 여부 |
| `max_stacks` | 누적 상한(없으면 무제한) |
| `weight` | 추첨 가중치(레어도 기본값에서 개별 미세조정) |
| `color` / `image` | 카드 색상/아이콘(없으면 색상·이모지 폴백) |

## 3. 레어도 체계

> **레어도 = 등장 가중치(weight).** 원본엔 rarity 개념이 없고 `weight`(20/10/4/1) 4단계만 있었음 → 그 가중치가 사실상 레어도. 아래는 원본 가중치를 그대로 이식(1:1 매핑). **개별 항목 가중치 미세조정은 밸런싱 후.**

| 레어도 | 성격 | 가중치 | 스택 |
|--------|------|--------|------|
| **커먼** | 소폭 누적 스탯, 안정적 | **20** (자주) | 대부분 stackable |
| **언커먼** | 중간 강화·짧은 액티브 | **10** (보통) | 일부 |
| **레어** | 빌드를 정의하는 강력 효과 | **4** (드묾) | 대부분 non-stack |
| **에픽** | 판을 바꾸는 희귀 효과 | **1** (매우 드묾) | non-stack |

> 원본 가중치 출처: `powerup_selection.gd`의 `POWERUP_DATA`(w20 5종 / w10 9종 / w4 하베스트매드니스 / w1 필드클리어).
> 후속 확장 여지: `legendary`(세션당 1회 등장, 초강력) — v2 안정화 후 검토.

### 4.10 아이템 (즉발형) — 맵 픽업 / 슬롯 저장 (확정)

**획득·사용 방식**
- **맵에서 줍기 + 상점 구매**(구 상자 대체): 맵 스폰 → 밟으면 획득 / 메인 메뉴 상점에서 코인 구매(세션 전 슬롯 프리로드). 슬롯 캡이 보유량 제한 → 남용 방지, 균형은 시뮬로.
- **슬롯 저장 + 스페이스 발동**: 즉시 사용 아님. 슬롯에 넣어두고 **인게임 스페이스로 발동**(원하는 타이밍). HUD엔 슬롯 아이콘만(텍스트 X).
- 강한 아이템(하베스트 매드니스·오버드라이브 등)을 **거목전용으로 비축** 가능 → 보스전 전략.
- 슬롯 초과 시 교체(또는 즉시 사용).

**관련 스킬 (탐험 그룹)**
- **아이템 슬롯 스킬(신규)**: 저장 슬롯 **1 → 2 → 3**. 기본 1칸.
- **씨앗 확률 스킬**: 기존 `chest_chance` 리퍼포즈 → **거목 소환 씨앗** 등장 확률↑(§3.2). 아이템(즉발) 등장 확률 스킬은 없음(맵 발견+상점 구매로 획득).

## 5. 시너지 · 빌드 예시 (재미 포인트)

- **치명타 리퍼 빌드**: `pu_crit_chance` + `pu_crit_damage` + `critical_reaper` + `execute` → 치명타 연쇄 즉사.
- **황금 경제 빌드**: `pu_golden_chance` + `golden_luck` + `midas` + `coin_value` → 황금풀 눈덩이 + 파워업 재획득 루프.
- **광역 수확 빌드**: `pu_attack_range` + `pu_attack_speed` + `regrow_speed` + `coin_value` → 넓게 빠르게 쓸어담기.
- **콤보 폭주 빌드**: `pu_move_speed` + `momentum` + `combo_harvest` + `regrow_speed` → 쉬지 않고 이동하며 배율 유지.
- **벌목/보스클리어 빌드**: `timber` + `stun_resist` + `thorns` + (아이템)`uproot` + (룬)벌목꾼 → 거목/정예를 빠르게 격파(스턴 반사까지 활용).
- **오버킬 경제 빌드**: `sharp_blade` + `overkill` + `coin_value` + (아이템)`heavy_blade` → 압도적 공격력으로 처치 초과분까지 코인화.
- **씨앗 순회 빌드**: `seed_blessing` + `pu_move_speed` + `pu_magnet_range` + `chain_reaction` → 씨앗 모으며 이동, 상시 스탯 버프로 쓸어담기.
- **하이리스크 빌드**: `all_in` + `cursed_scythe` + `double_or_nothing` → 짧고 굵게 대박.

> 이런 시너지가 성립하려면 3택이 자주 등장해야 함 → **레벨업 빈도 + 상자 확률**이 로그라이트 템포의 핵심 파라미터(§7 밸런싱).

## 6. 구현 노트

- **이식 기반**: 원본 `powerup.gd`(정의) / `powerup_selection.gd`(3택 UI·추첨) / `chest.gd`(드롭) / `game_manager.gd`의 `apply_powerup()`·세션 버프 변수들. 클린 슬레이트이므로 필요한 부분만 이식(§`pc-port-plan.md`).
- **효과 적용 지점**: 스탯형은 `GameManager`의 세션 버프 배율(`session_buff_*`)로, 발동형(액티브)은 타이머/`timed_buffs`로 처리. (무기형/패턴형 파워업은 제거되어 신규 노드 로직 불필요)
- **스택 표시**: stackable은 카드에 `Lv.n → Lv.n+1` 표기(원본 `powerup_selection.gd:332-343`).
- **선택 UI(PC)**: 마우스 hover/포커스, 3(또는 4)장 가로 배치, 반응형(`pc-port-plan.md §5`). 키보드 방향키+엔터 선택도 고려.
- **아이콘**: 40종+ → 원본 아이콘 재사용 + 신규 제작. 미보유 시 색상/이모지 폴백 허용.
- **문자열**: 모든 name/desc는 `tr()` 키(=한국어 원문)로 관리(`pc-port-plan.md §3.6`).
- **시뮬 모델(구현 완료)**: 33종 파워업(지속)이 `sim/balance_sim.py`에 **StatBlock 수정자 + 레벨업 3택 드래프트 + 구간(phased) 램프**로 반영됨(`python3 sim/balance_sim.py powerups`). 실측 인런 코인배율 ≈ **1.56~2.0**(상한 2.0), 거목 DPS 기여 ×1.5. 이를 감안해 코인비용 ×1.5·거목 HP 900으로 재밸런싱(`pc-port-plan.md §3.8`).

## 7. 미결정 / 밸런싱 필요

1. **인런 리셋 범위**: 세션 종료 시 파워업 전부 리셋 확정? (누적 세션형 하이브리드 여지)
2. **레벨업/상자 빈도**: 로그라이트 템포 결정 핵심 수치.
3. **커먼 스택 상한(`max_stacks`)**: 무한 누적 시 후반 과성장 → 상한/체감곡선 설계.
4. ~~패턴형 성능비용~~ → **해결**: 무기형/패턴형 파워업 제거(정적 풀에 안 맞음).
5. ~~치명타 시스템 정식화~~ → **해결**: 원본에 이미 치명 스킬(`crit_chance` 0→100%, `crit_damage` 1.2x→3.7x)로 정식화됨(`get_crit_chance()`/`get_crit_damage_mult()`). 인런 파워업은 그 위에 **가산 세션 보너스**로 얹음(타입명 `pu_crit_*`로 스킬 타입과 분리).
6. **최종 개수**: **50종** (파워업 33 + 아이템 17). 무기형 5종 제거 + 목록 정리(회오리낫·시계태엽·정지집중·크리티컬서지 제거, 벌목·굳은심지·연쇄반응·씨앗축복·레벨업충격·가시반격·오버킬환원 추가) 반영. 안정화 후 레전더리 티어로 추가 확장 여지.
7. **⚠️ 시뮬 집중 감시 대상** (과성장 위험):
   - **세션 영구 성장 2종** `snowball`(풀당 공격력 영구↑) · `compound`(레벨업당 전스탯 영구↑) — 세션 길수록 무한 스노볼링. 상한/증가폭 엄격 조정.
   - **경제 곱연산** `interest`(보유코인 %) · `combo_harvest` · `coin_value` 중첩 시 코인 폭주.
   - **초반 과강** `coin_leech`(풀당 정액 +1) — 새싹($1) 대비 실효 배율이 초반에 지나치게 큼.
   - **보스킬러 남용** (아이템)`uproot` · `thorns`(스턴 반사 2%/회) — 거목 체력 밸런스 무력화 가능 → 반사율/가격/맵전용 안전장치.
   - **HP 무시 처치** `chain_reaction`(전파 즉사) — 고체력 풀 grind 스킵이라 밀집 월드에서 과수입 가능 → 확률/전파 상한 감시.
   - **오버킬 상한** `overkill` — +100% 상한이 실제로 새싹 남용 막는지 검증(상한 없으면 고데미지+싸구려풀 폭주).
